# akaditimultitech

Landing page for **Akaditi Multitech Industrial Services** (Accra, Ghana).

## Live

- Preview: https://akaditi-multitech.trinitystechnologies.workers.dev
- Domain: https://akaditimultitech.com (pending DNS attach)

## Local

```bash
# Simple static preview
python3 -m http.server 8765

# Or with Wrangler
npm install
npm run dev
```

## Deploy (Cloudflare)

```bash
npm install
npx wrangler login   # use the account that owns akaditimultitech.com
npm run deploy
```
